# Code of Conduct

SANORA OS is an international project. We want it to be a place where people
can work on a Linux distribution without harassment, regardless of experience
level, background, identity, language, location or hardware.

## Expected behaviour

- Be respectful and precise. Critique technical work, not people.
- Assume good faith, but verify claims with evidence.
- Give newcomers room to learn; explain decisions and link to documentation.
- Use English in shared project spaces so everyone can follow the discussion.
- Respect licences, trademarks and the work of upstream projects.
- Do not publish anyone's private information without explicit permission.

## Unacceptable behaviour

- Harassment, insults, discrimination, threats or sexualised language.
- Doxxing, publishing private communications, or targeted personal attacks.
- Deliberately misleading claims about test results, benchmarks, hardware
  support, licences or security properties.
- Sustained disruption of issues, pull requests, reviews or discussions.
- Retaliation against anyone who reports a concern in good faith.

## Scope

This applies to the GitHub repository (issues, pull requests, reviews,
discussions, commit messages, wiki), project documentation, and any project
communication channel or event. It also applies when someone represents the
project in public.

## Reporting

Report concerns privately through the GitHub repository's security advisory
flow or by contacting the maintainers via the repository. See
[SECURITY.md](SECURITY.md) for the reporting process. Include what happened,
where, and any relevant links or dates. Reports are handled confidentially and
without retaliation.

Maintainers may warn, edit/remove content, temporarily block interaction, or
exclude a participant, depending on severity and repetition. Significant
actions are recorded with a rationale.

## Attribution

This is an original, deliberately short code of conduct written for SANORA OS.
It is not copied from any third-party template. It may be replaced by a
community-reviewed text later through an explicit ADR.
